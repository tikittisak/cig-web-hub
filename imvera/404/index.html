1 Change notes สร้าง 2026-09-07

Highรอ IT
หน้า 404 (live) ยังใช้ข้อความ default ของระบบ ไม่มีโลโก้/แบรนด์เลย

→ ใช้ prototype ด้านบนแทน — nav/footer ใช้เนื้อหาจริงจากเว็บ (ทั้งลิงก์ menu, สี, ข้อมูลบริษัทในฟุตเตอร์) ไม่ใช่ของแต่งเอง

Highรอ IT
ไฟล์เป็น static HTML เดียว รับรอง HTTP status เองไม่ได้ — เสี่ยงเป็น "soft 404" (server ตอบ 200 ทั้งที่เนื้อหาคือ error)

→ IT ต้องตั้ง server ให้หน้านี้ตอบ status 404 จริง ไม่ใช่ 200 — เช็คด้วย curl -I หลัง deploy

ทำตาม Google 404 standard แล้ว
ข้อความชัดเจน+เป็นมิตร · nav/footer เหมือนหน้าอื่นจริง · ลิงก์ยอดนิยม (3 product) + กลับหน้าแรก · ไม่ auto-redirect · มีจุดแจ้ง broken link · noindex เดี่ยว (ไม่ตัด nav link equity ด้วย nofollow)
