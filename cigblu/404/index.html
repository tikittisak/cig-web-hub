1 Change notes UAT 2026-08-03 · Google-standard review 2026-08-28

🎨 UI — แบรนด์
Medรอ IT
หน้า 404 (live) ยังใช้ข้อความ default ของระบบ ไม่มีโลโก้/แบรนด์

→ ใช้ prototype 404.html ด้านล่างแทน (nav/footer = production shell จริง ไม่ต้องแตะ) — มี "Back to home" / "Contact us" + quick-link การ์ดไป Products/Solutions/Insights/Contact กันคนตกหลุม dead-end

🔍 SEO — Google 404 standard
Highรอ IT
ไฟล์เป็น static HTML เดียว รับรอง HTTP status เองไม่ได้ — เสี่ยงเป็น "soft 404" (server ตอบ 200 ทั้งที่เนื้อหาคือ error)

→ IT ต้องตั้ง server ให้หน้านี้ตอบ status 404 (หรือ 410) จริง ไม่ใช่ 200 — เช็คด้วย curl -I หรือ Network tab หลัง deploy ไม่งั้น Google ขึ้น "Soft 404" ใน Search Console และไม่ตัดหน้าออกจาก index (ข้อกำหนดหลักของ Google, ตัวเดียวที่แก้ในโค้ด HTML ไม่ได้)

สถานะดี
ผ่านตาม Google Search Central ที่เหลือ: ข้อความชัดเจน+เป็นมิตร · nav/footer เหมือนหน้าอื่น · ลิงก์ยอดนิยม + กลับหน้าแรก · ไม่ auto-redirect ไปหน้าแรก (กัน soft-404 อีกแบบ) · เพิ่มจุด "แจ้ง broken link" แล้ว · noindex เดี่ยว (ตัด nofollow เดิมออก — ไม่มีในด็อกจริงของ Google และกันลิงก์ nav โดยไม่จำเป็น)
