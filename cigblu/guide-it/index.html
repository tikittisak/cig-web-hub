แถวบนเป็นตัวอย่างการกรอก ไม่ใช่ผลจริง

1 ความเร็ว (PageSpeed)

  1. เปิด pagespeed.web.dev → วาง URL → กด Analyze
  2. เลือกแท็บ Mobile (ดู Desktop ด้วยแต่ Mobile สำคัญกว่า)
  3. จดค่า 3 ตัวในส่วน "Diagnose performance issues": LCP, CLS, TBT + คะแนน Performance
  4. กดซ้ำ 3 ครั้ง ใช้ค่ากลาง (ผลแต่ละรอบไม่เท่ากัน)
  5. ถ้าส่วนบน "Discover what your real users are experiencing" มีข้อมูล ให้จด INP ด้วย (มีเมื่อเว็บมีคนใช้จริงพอ — หลังย้ายโดเมน)
ค่าแปลว่าผ่านเมื่อ
LCPเวลาที่ภาพ/ข้อความใหญ่ที่สุดบนจอแรกโหลดเสร็จ≤ 2.5 วินาที
CLSหน้ากระตุก/เลื่อนเองระหว่างโหลด≤ 0.1
TBT (แทน INP ในการทดสอบ)เวลาที่หน้าค้าง กดอะไรไม่ได้ เพราะ JavaScript≤ 200 ms
INP (ข้อมูลผู้ใช้จริง)กดแล้วหน้าตอบสนองช้าแค่ไหน≤ 200 ms

2 มือถือ

  1. ทดสอบบนเครื่องจริง: iPhone (Safari) 1 เครื่อง + Android (Chrome) 1 เครื่อง
  2. บนคอม: Chrome → กด F12 → ไอคอนมือถือ (Toggle device toolbar) → ลองความกว้าง 360, 390, 768 px
  3. เช็คล้นแนวนอน: ใน Console พิมพ์ document.documentElement.scrollWidth > innerWidth → ต้องได้ false
เช็คผ่านเมื่อ
เมนู ☰เปิด/ปิดได้ · ทุกลิงก์ในเมนูกดได้ · ไม่ถูก header บัง
ล้นแนวนอนไม่ต้องเลื่อนซ้าย-ขวาทุกหน้า (ผลคำสั่งด้านบน = false)
ขนาดตัวอักษรเนื้อหาอย่างน้อย 16px อ่านได้โดยไม่ต้องซูม
ปุ่ม/ลิงก์สูงอย่างน้อย 44px และไม่ชิดกันจนกดผิด
ฟอร์ม Contactกรอกได้ครบ · แป้นพิมพ์อีเมลขึ้นในช่อง Email · ปุ่ม Submit ไม่ถูกบัง
เบอร์โทร / LINEกด tel: แล้วโทรออกได้ · ลิงก์ LINE เปิดแอปได้

3 Accessibility (ใช้งานด้วยคีย์บอร์ด / screen reader)

  1. ใน PageSpeed ดูคะแนน Accessibility → ต้อง ≥ 90 · เปิดรายการที่ไม่ผ่านแล้วแก้ตามที่บอก
  2. ติดตั้งส่วนขยาย Chrome "axe DevTools" (ฟรี) → F12 → แท็บ axe → Scan → แก้ข้อที่เป็น Critical / Serious
  3. วางเมาส์ไว้ห่างๆ แล้วใช้แค่ปุ่ม Tab, Shift+Tab, Enter, Esc ไล่ทั้งหน้า
เช็คผ่านเมื่อ
Tab ครั้งแรกเจอลิงก์ "Skip to content" (ยังไม่มี — ดูหน้าเมนู ข้อ 6)
กรอบ focusเห็นชัดทุกครั้งว่ากำลังอยู่ที่ปุ่ม/ลิงก์ไหน
เมนู dropdownเปิดด้วย Enter ปิดด้วย Esc
ฟอร์มทุกช่องมีชื่อ (label) · กรอกผิดแล้วมีข้อความบอกว่าผิดตรงไหน
รูปรูปที่มีความหมายมี alt บอกว่าเป็นรูปอะไร · รูปตกแต่งใช้ alt="" (ตอนนี้ผ่านแล้ว)
สีตัวอักษรaxe ไม่แจ้ง "color contrast"

4 SEO + AI crawler

หลักข้อเดียวที่ต้องจำ: AI crawler (GPTBot ของ ChatGPT, ClaudeBot, PerplexityBot) ส่วนใหญ่ไม่รัน JavaScript — เห็นแค่ HTML ที่ server ส่งมา · อะไรที่สร้างหลังโหลด (เช่น เมนู dropdown ตอนนี้) หรือฝังในรูป จะไม่ถูกเห็นเลย

วิธีเช็คแบบง่าย: เปิดหน้า → กด Ctrl+U (View Source) → กด Ctrl+F ค้นหาข้อความหรือลิงก์ที่ต้องการ → ถ้าไม่เจอ แปลว่า crawler ไม่เห็น
หรือใช้คำสั่ง curl -s https://web.cigblusolutions.com/products | grep -o 'href="/products[^"]*"'

เช็คทุกหน้าผ่านเมื่อ
<title>ไม่ซ้ำกับหน้าอื่น · ≤ 60 ตัวอักษร · รูปแบบ <ชื่อหน้า> | CIG BluSolutions (ไม่มีชื่อแบรนด์ซ้ำ 2 ครั้ง)
meta description120–155 ตัวอักษร พูดถึงเนื้อหาหน้านั้นจริง
<h1>มี 1 อันต่อหน้า (ตอนนี้ผ่าน) · หัวข้อเรียง h1 → h2 → h3 ไม่ข้ามชั้น
canonicalชี้ URL ของหน้าตัวเองบนโดเมนจริง ไม่มี / ท้าย · ทุกหน้าใช้โดเมนเดียวกัน
og:title / og:description / og:image / og:urlมีครบ · og:image ขนาด 1200×630 ของหน้านั้น
ข้อความสำคัญเป็นข้อความ HTML ไม่ฝังในรูป
ลิงก์เป็น <a href="..."> จริง ไม่ใช่ปุ่มที่ใช้ onClick พาไป · ไม่มีลิงก์ไป #
Status codeหน้าจริง = 200 · ย้ายแล้ว = 308/301 · ไม่มีหน้า = 404 (ตอนนี้ 404 ผ่าน)

JSON-LD (ข้อมูลโครงสร้าง) — ใส่ตามประเภทหน้า:

หน้าใส่ type
HomeOrganization (มีแล้ว) + WebSite
รุ่นสินค้าProduct (name, description, image, brand) + BreadcrumbList
family / กลุ่มย่อยCollectionPage + BreadcrumbList
SolutionsService + BreadcrumbList
InsightsArticle (headline, datePublished, author, image)
ContactOrganization + ContactPoint

ตรวจด้วย Rich Results Test → วาง URL → ต้องไม่มี error

ไฟล์ระดับเว็บ:

ไฟล์ผ่านเมื่อ
robots.txtอนุญาต AI crawler (ผ่านแล้ว) · บรรทัด Sitemap ชี้โดเมนจริง
sitemap.xml1 URL ต่อ 1 หน้า · ไม่มีหน้าซ้ำ / template / 404 · ใช้โดเมนจริง
llms.txtลิงก์ทุกอันตอบ 200 และตรงกับ sitemap
stagingweb.cigblusolutions.com ตอบ header X-Robots-Tag: noindex — เช็คด้วย curl -sI https://web.cigblusolutions.com/ | grep -i robots

หลังย้ายไป www.cigblu.com: ยืนยันโดเมนใน Google Search Console → ส่ง sitemap → ใช้ "URL Inspection" กับ 6 หน้าด้านบน → ดูรายงาน "Pages" ทุกสัปดาห์ 4 สัปดาห์แรก ว่าไม่มี 404 / redirect error เพิ่ม
