1 Change notes สิ่งที่หน้านี้/section ต้องแก้

  • Stub → replace main content: /contact บนเว็บ live (web.cigblusolutions.com/contact) ยังเป็น "Content coming soon" — ไม่มี form, map, ที่อยู่ หรือ footer เลย IT เอา main content จาก prototype (contact.html ด้านล่าง) ไปแทน stub ได้เลย — nav กับ footer ในไฟล์ prototype คือ production shell จริงที่ IT build ไว้แล้ว ไม่ต้องแตะ
  • อีเมลมาตรฐาน — แก้แล้ว: contact@cigblu.com คือมาตรฐาน แก้ใน prototype แล้วทั้ง visible text และ JSON-LD (hero panel, map/CTA mailto, Organization + ContactPoint) ยกเว้น footer ที่เป็น verbatim IT shell ยังเขียน contact@cigblusolutions.com อยู่ — ถ้าจะให้ตรงกัน ต้องไปแก้ที่ไฟล์ต้นทางจริง site/site-shell/footer/footer.html แยกต่างหาก (นอก scope หน้านี้)
  • SEO/AI crawler pass (2026-08-27) — แก้แล้ว: สะกด "enquiry" (British) → "inquiry" (US standard ตาม design-standard §9) ทั้ง meta description, h3, hero copy · เพิ่ม <h2> คลุม section แรก (เดิมกระโดด h1→h3 ไม่มี h2) ให้ตรง pattern กับ section อื่น · JSON-LD contactType เปลี่ยนจาก "customer support"/"office" (ไม่ใช่ค่าที่ Google รู้จัก) เป็น "customer service"/"sales"
  • Form submit: ปุ่ม Submit ของฟอร์ม inquiry ตอนนี้เป็น draft เฉยๆ (ยังไม่ต่อระบบ) — IT ต้องต่อเข้า CRM/email workflow จริง พร้อม privacy consent
  • Google Maps: prototype ใช้ embed แบบ keyless (ไม่ต้อง API key) ใช้ launch ได้เลย ถ้าบริษัทมี Maps API key ของตัวเองค่อยเปลี่ยนทีหลัง ไม่บล็อกการ launch
