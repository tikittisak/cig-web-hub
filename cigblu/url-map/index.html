แผนที่ URL + redirect

URL ที่ตกลงแล้ว (Ti อนุมัติ 2026-10-27) เน้น SEO และ AI crawler — เปลี่ยนก่อนย้ายไป www.cigblu.com จะถูกที่สุด เพราะยังไม่มีใครลิงก์มาที่เว็บทดสอบ

1 กติกา URL

  1. ตัวพิมพ์เล็กทั้งหมด คั่นคำด้วย - ไม่มี .html ไม่มี / ท้าย
  2. โครงสร้าง /products/<family>/<รุ่น> ลึกไม่เกิน 3 ชั้น — URL บอกได้ว่าสินค้าอยู่กลุ่มไหน
  3. ใช้คำที่ลูกค้า/วิศวกรค้นหาจริง ขึ้นต้นด้วยประเภทสินค้า เช่น air-cooled-condenser-ec-fan
  4. ไม่ใช้รหัสภายใน (ACC, CU-SH) ปี หรือคำแคมเปญ
  5. 1 หน้า = 1 URL: canonical ชี้ตัวเอง, อยู่ใน sitemap ครั้งเดียว, BreadcrumbList ตรงกับ path, llms.txt ใช้ URL เดียวกัน
  6. URL เก่าทุกอัน redirect แบบ 308/301 ไปหน้าที่ใกล้ที่สุด — ไม่โยนไปหน้าแรกทั้งหมด
