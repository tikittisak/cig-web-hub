6 กติกาการทำงานของเมนู

เรื่องต้องเป็นแบบนี้
Crawler มองเห็นrender ลิงก์ dropdown ทั้งหมดใน HTML ตั้งแต่โหลดหน้า แล้วซ่อนด้วย CSS (ไม่ใช่สร้างตอน hover) · ตรวจ: เปิด View Source (Ctrl+U) แล้วค้นหา /products/marine-hvac ต้องเจอ
ลิงก์จริงทุกหัวข้อและทุกรายการเป็น <a href> ไม่ใช้ <button> หรือ onClick แทนลิงก์
ลูกศร ▾แสดงเมื่อ hasDropdown: true และมีลิงก์อย่างน้อย 1 อันเท่านั้น
คีย์บอร์ดTab ไปถึงทุกหัวข้อ · Enter/Space หรือ ↓ เปิด dropdown · Esc ปิดและกลับไปที่หัวข้อ · มีกรอบ focus มองเห็นชัด · ใส่ aria-expanded บนตัวเปิด dropdown
หน้าที่อยู่หัวข้อของหน้าปัจจุบันใส่ aria-current="page" และสีเน้น
Skip linkเพิ่ม <a href="#main" class="skip-link">Skip to content</a> เป็นลิงก์แรกของหน้า (ซ่อนจนกว่าจะได้ focus) และใส่ id="main" ที่ <main>
มือถือปุ่ม ☰ มี aria-label="Open menu" + aria-expanded · ปุ่ม/ลิงก์สูงอย่างน้อย 44px · เปิดเมนูแล้วหน้าไม่เลื่อนข้างหลัง · ไม่ล้นแนวนอนที่ 360px
Hoverเปิดเมื่อชี้ หน่วงปิด ~200ms (ของเดิมทำแล้ว) · กดหัวข้อ = ไปหน้ารวม
